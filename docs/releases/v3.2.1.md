# v3.2.1 发布说明（待发布）

## 新增

- 单词测试结果页可撤销本次新增的错题；测试前已有错题和其他测试产生的记录继续保留。
- 错题本支持分页及每页 10、20、50 条选择；复习当前筛选仍涵盖全部筛选结果。

## 优化

- 主题颜色切换加入更平滑的动画，快速连续切换时避免旧动画干扰新选择。
- 页面、课文及学习数据加载采用统一的加载指示；清除离线缓存前使用确认窗口说明影响范围。
- 重练准备和撤销期间显示加载状态，暂时禁用结果页操作，避免重复点击影响下一次测试。

## 修复

- 修复单词 Unit 和自定义词表选中状态与选择计数不一致的问题。
- 修复账户菜单中用户名与邮箱重叠，并保持头像大小稳定。
- 账户登录入口不再等待学习同步状态加载，避免同步检查阻塞登录；离线时仍不可登录。

## 已知限制

- 完整测试历史和未完成测试暂不参与云端学习同步。
- 云端功能需要登录和网络；离线时仍可使用已缓存的本地学习工具。

## 升级注意事项

- 保留本机设置、错题本、掌握度和已缓存的学习数据；更新应用页面缓存以获取新版界面。
- 清除离线缓存仍只清理缓存，不清理错题本、掌握度或设置。
- 撤销仅针对本次新增错题，不会删除测试开始前已有的错题。

## 发布准备

- 从 dev 准备 v3.2.1；版本准备分支先提交到 dev，随后由仓库所有者手动 Review dev → main 发布 PR，按本次授权规则使用 rebase 合并。
- main 推送会触发现有发布工作流，重新验证后自动创建 v3.2.1 标签和 GitHub Release；合并前请确认版本准备已进入 dev。
- 本次准备不手动创建标签、不发布、不合并 PR。
