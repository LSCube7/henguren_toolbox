# 学习数据自动同步

## 使用范围

在账户页主动开启后，自动合并当前账户的错题本与掌握度。开关按本机账户分区保存，默认关闭，不随设备设置上传。访客数据仍需确认转入；开发者自定义 R2 仍仅手动同步。主题、语言、缓存、完整测试历史和未完成测试不在范围内。覆盖云端仍需明确确认。

## 触发与读取控制

本地修改与修改版本在同一 IndexedDB 事务提交，暂停修改 10 秒后上传，持续修改最长 60 秒尝试一次。有修改时直接调用合并上传，无需预先读取云端状态。上传确认只确认请求时的本地版本，期间的新修改留待下一轮。

应用打开且前台时，每 5 分钟查询云端对象版本，版本改变才下载完整快照。回到前台及联网恢复时也检查，正常版本检查至少相隔 60 秒。页面隐藏时停止轮询；不保证应用关闭后的后台同步。导航栏和学习页面共用同步状态，同一页面普通状态读取缓存 60 秒，手动刷新和覆盖确认可强制更新。

手动与自动学习同步共用队列及跨标签页 Web Lock；无 Web Locks 时使用 IndexedDB 有限租约避免并发任务。后续标签页在取得锁后重新读取已保存的修改版本及检查时间，跳过已完成任务。每个新页面首次仍会读取账户同步概况，不保证不同标签页首次概况请求完全去重。

云端合并结果学习内容不变时不生成新版本、不写当前对象也不创建备份；仅同步时间等变化不会产生写入。非空云端存在且确有变化时，保留原有写入前快照和候选快照备份。历史备份不会自动清理。版本查询仍属于 R2 读取操作，减少的是频率与完整快照传输。

## 失败与账户切换

网络、服务和备份暂时失败时，从约 15 秒、30 秒逐步退避至最多 5 分钟，并加入随机延迟。登录失效、无效数据、快照超限或本地应用失败暂停自动重试，用户处理后可手动刷新重试。离线保留修改和账户归属。

主动退出前停止调度并取消进行中的客户端请求；退出失败可恢复调度。账户切换后旧页面回调必须通过持久化归属检查才能写入本地。客户端取消请求不保证已经到达服务端的写入被撤销，服务端仍以请求账户和条件写入保护目标。已上传且未改动的数据清理、未上传修改保留原分区的规则继续有效。清理本机副本后重登并开启自动同步，会重新检查并拉取云端。

## 限制和验证

掌握度仍选择较新整条记录，不累计多设备同时复习的次数。多设备变化可能延迟到前台检查时显示，可手动刷新。真实 R2 联调使用独立测试桶、临时凭据和虚构账户，不触碰正式数据。执行方式见 [隔离 R2 联调](./vocab-cloud-sync-integration.md)。

## 开发验证记录

112 项自动化测试、lint、类型检查和生产构建通过。隔离浏览器使用模拟云端验证默认关闭、主动开启、导航与页面共用一次概况读取、真实删除的修改版本、上传途中继续修改、延迟上传、跨标签页单次上传、无 Web Locks 时的 IndexedDB 租约、离线恢复、会话过期保留及重登恢复。版本未变时只查询版本；版本变化才下载，下载不会触发重复上传。原有访客迁移、主动转入、退出清理、账户隔离和数据库升级被旧标签页阻止后的重试流程也通过回归。中英文导航在禁用 JavaScript 时仍有静态内容，英文登录保留语言返回路径。

验证副本复用现有依赖，字体生成及构建环境调整仅在副本中执行，未纳入功能提交。真实 R2 未写入。

## 导航入口

Rail 的同步图标打开同步面板，图标与颜色继续表示当前同步状态。未登录时仅显示本机保存说明与登录入口。登录后集中显示一次状态、账户、有效的上次成功时间、自动同步和“立即同步”（合并上传）；“更多操作”收纳拉取、覆盖、刷新、数据概况和说明。覆盖仍须确认。离线保留状态与已开启的自动同步开关以便关闭，隐藏不可用的云端操作；自定义来源仅显示手动操作。桌面在图标旁展开，移动端使用底部面板。账户页保留数据归属和访客转入，旧 #wrongbook-sync 链接仍打开面板。头像菜单显示头像、用户名和可用邮箱，可查看账户、登录或退出。离线不允许登录和退出，登录返回当前页面并保留语言。

账户菜单浏览器回归已验证桌面/移动端视口、键盘展开与 Esc 关闭及焦点返回、离线禁用、退出失败保留数据、退出成功保留未上传数据、中英文菜单、登录返回页面的语言/查询/锚点，以及会话过期后的重新登录入口。退出清理与账户隔离原有回归通过。

同步面板浏览器验证：开启面板不新增概况读取，合并/拉取/覆盖及取消、版本变化拒绝覆盖、同步期间禁用重复操作、自动开关、离线和未登录、桌面定位与移动端底部面板、Esc/焦点恢复及旧链接兼容均通过。头像与邮箱使用模拟资料验证。自定义来源仍手动同步；上次成功时间读取当前账户的既有本地记录，自定义来源暂不持久记录该时间。

精简菜单回归：中英文未登录仅显示说明与登录入口，无未替换的数量变量；登录后的状态只展示一次，其余操作折叠；离线隐藏云端操作并可关闭已开启的自动同步；服务器不可用后可刷新恢复。桌面和移动端截图、全部手动操作、覆盖取消与冲突保护、忙碌状态、焦点恢复和自定义来源回归通过。112 项测试、lint、类型检查和生产构建通过，未写真实 R2。

## 认证失效边界

即使账户查询成功，只要账户同步请求返回 401，也会清除共享状态中的头像、用户信息与云端概况，并显示重新登录。自动同步暂停重试；本机账户分区、错题、掌握度和自动同步偏好保留，不执行退出清理。重新登录或明确刷新成功后可恢复。初次概况、手动上传和版本查询的浏览器回归通过。
