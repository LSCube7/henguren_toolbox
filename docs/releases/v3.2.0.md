# v3.2.0 发布说明（待发布）

## 新增

- 单词掌握度与错题本一起同步，支持跨设备继续复习；旧快照缺少掌握度时不会清空已有进度。
- 本机学习数据按账号隔离，访客学习数据转入当前账号前需要用户明确确认。
- 新增可选自动学习同步，默认关闭，按本机账号分别开启；设置同步继续保持手动操作。
- 账号菜单提供头像、邮箱和学习同步入口，桌面使用悬浮卡片，手机使用同步抽屉。

## 优化

- 界面升级为 Material 3 Expressive，统一导航、卡片、按钮组、主题选色和动画；保留种子色、Pride Colors、自定义颜色和系统明暗模式。
- 中英文页面使用独立语言地址，保留旧链接访问、查询参数及页面锚点，改善静态首屏和离线缓存。
- 优化单词提示、词表选择操作、打印语言选择、结果展示及文学常识筛选。
- 登录品牌统一为 CubeID。

## 修复

- 改善云端快照更新、账号切换、会话过期和自定义同步源凭据变更后的同步状态。
- 修复跨标签学习数据通知，以及自动同步在远端数据变化后的收敛问题。
- 修复导航整页重载、移动抽屉点击穿透、键盘焦点循环和同步面板布局动画问题。

## 已知限制

- 完整测试历史和未完成测试暂不参与云端学习同步。
- 云端功能需要登录和网络；离线时仍可使用已缓存的本地学习工具。
- M3E 是社区实现，并非 Google 官方组件库。

## 升级注意事项

- 旧本地学习数据保留为访客数据；如需归入账号，请登录后明确选择转入。
- 自动学习同步需要用户主动开启，不会因升级自动启用；主题、语言等设置继续显式同步。
- 本次更新不要求重新配置已有外观设置；会话过期时需要重新登录。

## 发布准备

- 版本号为 3.2.0；准备 PR 必须使用 Merge commit 合入 dev，以保留 main 的历史连接。
- 随后手动 Review dev → main 发布 PR，并使用 Merge commit 合并。
- 现有 main 发布工作流会重新执行测试、lint、类型检查和构建，然后自动创建 v3.2.0 标签及 GitHub Release；本次准备不会手动创建标签或发布。
