# v3.2.2 发布说明（待发布）

## 新增

- 首次访问可直接开始学习，无需先完成设置；首页提供可关闭的欢迎卡片和主动开启的功能导览，个人设置可重新查看导览。
- 登录账户默认开启错题本与掌握度的自动合并同步，并提供同步气泡说明；可在同步面板关闭。

## 优化

- 个性化设置改为可选，可随时退出并保留已应用的偏好；检查云端设置失败时可重试或继续使用本机设置。
- 调整中英文按钮、设置与提示文案，让登录、同步和学习操作更清楚。
- README 按生产部署、备份维护和上线检查重新组织。
- 运行环境统一为 Node.js 26.13.0、pnpm 12.18.0，Next.js 升级至 16.4.5；部署环境需要同步更新。

## 升级注意事项

- 自动同步只处理当前账户的错题本与掌握度。旧版未记录明确关闭选择的设置会迁移为开启；升级后明确关闭的选择会保留。
- 访客数据仍需用户确认后才转入账户；转入后可能随账户自动同步。主题、语言等设备设置与开发者自定义同步源继续手动同步，不自动覆盖云端或本机数据。
- 保留本机设置、错题本、掌握度与已缓存学习材料。已完成旧版初始设置的用户不再显示首页欢迎卡片。
- 自托管部署请使用项目声明的 Node 与 pnpm 版本，按锁文件安装依赖后重新构建。已有 OAuth、会话与 R2 配置无需因本次发布更换。

## 已知限制

- 完整测试历史、未完成测试和临时自定义词表暂不参与自动同步。
- 自动同步需要页面运行、有效登录和网络；离线时仍可使用已缓存的学习工具。

## 发布准备

- 基线：dev 的 0e7fee2；相对 v3.2.1 汇总已集成变更。
- 准备分支先提交到 dev；待仓库所有者手动 Review 后，再从 dev 向 main 准备发布 PR。合并策略遵循仓库所有者本次要求，不由代理执行合并。
- main 推送会触发现有发布工作流，检查通过后自动创建 v3.2.2 标签及 GitHub Release。
- 本次准备不手动创建标签、不发布、不部署、不合并 PR。
