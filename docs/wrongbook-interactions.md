# 错题本交互

- 测试答错后仍立即保存。结果页的“本次不加入错题本”撤销本次为新单词产生的错题尝试；测试开始前已有错题及其掌握度更新保留。
- 其他测试或页面后来产生的尝试保留。撤销会保存对应的删除标记，云端合并时不会恢复已撤销的尝试。
- 完全移除的新错题会清理对应掌握度。若保存或清理失败，页面显示错误，可再次尝试。
- 提前结束测试也可撤销；重练错题视为新一次测试，以重练开始时的错题本为基线。
- 单词及批次视图默认每页 20 条，可选 10、20、50 条。改变筛选、搜索或视图后回第一页，删除后页码自动限制在有效范围。
- “复习当前筛选”始终使用全部筛选结果，不受当前分页影响。批次视图仍展示全部批次。
- 分页位于记录列表底部，桌面端靠右。窄屏下每页条数独占一行，范围提示简化，保留上一页和下一页操作，避免横向滚动。
